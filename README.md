#SaaS Data Analysis Project

By: Kumari Ayushi

A SaaS company analysis using SQL, Python (Jupyter), and Excel.

#How to run

SQL (MySQL Workbench):

Install MySQL Server + MySQL Workbench
Open and run saas_mysql_dump.sql
Open analysis_queries_mysql.sql and run queries with Ctrl+Enter

Python (Jupyter):

pip install jupyter pandas matplotlib
jupyter notebook
Open SaaS_Analysis.ipynb, keep saas.db in the same folder
Run → Run All Cells

Excel:

Double-click SaaS_Dashboard.xlsx
Open the Dashboard tab to see KPIs and charts
